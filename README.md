# Metodo Follow-UP

Landing page profissional desenvolvida para o personal trainer **Gustavo Viana**, criador do **Metodo Follow-UP**.

O projeto foi construido do zero com foco em conversao, experiencia premium, responsividade, performance, SEO e contato rapido via WhatsApp.

## Visao Geral

O site apresenta o Metodo Follow-UP como um acompanhamento personalizado para treinos online, presenciais e hibridos. A proposta da pagina e transmitir autoridade, clareza e confianca para transformar visitantes em clientes.

Dominio principal:

```text
https://metodofollowup.com.br/
```

## Principais Recursos

- Hero premium com CTA para planos e WhatsApp.
- Header responsivo com menu desktop e menu lateral mobile.
- Secao "Sobre Mim" com foto, CREF, especialidade e numeros de alcance.
- Timeline animada em "Como Funciona" com progresso controlado por scroll.
- Galeria de feedbacks com layout inspirado em celular, miniaturas e navegacao touch.
- Secao de camisetas com video short, fotos frente/verso e CTA de compra.
- Cards de planos com destaque para o plano mais popular.
- Footer compacto com CTA final e link para Instagram.
- Animacoes com GSAP e ScrollTrigger.
- Fallbacks para cenarios sem GSAP ou com reducao de movimento.
- SEO tecnico com meta tags, Open Graph, Twitter Card, JSON-LD, sitemap e robots.

## Tecnologias

- HTML5 semantico
- CSS3 responsivo
- JavaScript vanilla
- GSAP
- ScrollTrigger
- Google Material Symbols

## Como Rodar Localmente

Por ser um site estatico, basta abrir o arquivo:

```text

```

Tambem pode ser servido por qualquer servidor estatico local, como extensoes de live server do editor.
